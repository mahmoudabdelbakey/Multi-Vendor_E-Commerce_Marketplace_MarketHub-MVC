# MarketHub-MVC Documentation Package

| File / Folder | What it contains |
|---|---|
| `MarketHub-MVC_Project_Documentation.docx` | The main editable Word document (Arabic RTL + English technical terms, 119 pages, embedded diagrams). |
| `MarketHub-MVC_Project_Documentation.pdf` | The same document as PDF for sharing. |
| `diagrams/png/` | Rendered diagrams (PNG) as embedded in the document. |
| `diagrams/svg/` | The same diagrams as SVG (vector). |
| `diagrams/src/` | Editable sources: `.mmd` (Mermaid) and `.dot` (Graphviz). |
| `diagrams/render.sh` | Re-renders every diagram from `src/` (needs Node + mermaid-cli + Graphviz). |
| `source/content/` | The document chapters as Markdown (edit these to change the text). |
| `source/build/` | `build.js` (Markdown to DOCX with RTL support) and `fix_bookmarks.py`. |
| `source/generators/` | `tools_collab.py` generates chapter 10 (rotation matrices + sprint plans). |

## Rebuilding the document
1. `./diagrams/render.sh` after editing any diagram source.
2. Edit the Markdown in `source/content/` (chapter 10 is generated by `tools_collab.py`).
3. Run `node source/build/build.js`, then `python3 source/build/fix_bookmarks.py <docx>`.
4. Convert to PDF with LibreOffice: `soffice --headless --convert-to pdf <docx>`.

Note: the build scripts use absolute paths (`/home/claude/pkg`); change the `ROOT` constant to your folder first.
The Table of Contents uses page-reference fields; in Word press F9 (Update field) if page numbers look stale.
