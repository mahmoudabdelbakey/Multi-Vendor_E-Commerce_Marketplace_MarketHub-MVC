# Business Rules

| ID | Rule |
|---|---|
| BR-01 | Review text is required for sentiment analysis. |
| BR-02 | Review length must comply with the API validation policy. |
| BR-03 | A prediction belongs to exactly one review in the MVP model. |
| BR-04 | Product references must resolve when the API requires product validation. |
| BR-05 | Admin analytics require authorization when security is enabled. |
| BR-06 | Model failures are not converted into fake sentiment labels. |
| BR-07 | Dataset licenses and provenance must be documented before redistribution/use. |
| BR-08 | A model version should be recorded if multiple model versions can coexist. |
